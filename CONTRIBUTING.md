# Contributing Guidelines

Thanks for considering contributing to Awesome SEO Tools. This list only stays valuable if every addition is genuinely useful.

## What We Accept

- Tools that are **actively maintained** (check for updates within the last year).
- Tools with a real, usable product — no landing-page-only projects.
- Free tools, freemium tools, and paid tools are all welcome, as long as the entry is honest about what it does.
- Open-source projects with clear licensing and documentation.

## What We Reject

- Dead or abandoned projects.
- Duplicate entries that already exist in the same category.
- Spam, affiliate-only pages, or tools without a real function.
- Anything that does not actually relate to SEO, search, crawling, or web analytics.

## How to Add an Entry

1. Open an issue with the tool name, URL, and a one-line description, **or** submit a pull request.
2. Place the entry in the correct category, keeping alphabetical order.
3. Follow the entry format:

```markdown
- [Tool Name](https://example.com/) - One-sentence description of what it does.
```

4. Keep descriptions factual — no hype, no keyword stuffing.

## Quality Bar

Before submitting, verify:

- [ ] The URL works and resolves to the actual product.
- [ ] The tool has real users or clear documentation.
- [ ] The description is unique and informative (not a copy of the tool's own tagline).

## Pull Request Process

1. Fork the repo and create a feature branch.
2. Make your change in a single commit.
3. Open the PR with a short summary of why the tool deserves a spot.
4. A maintainer will review within a few days. Be patient — quality over speed.

## Code of Conduct

This project follows the [Code of Conduct](code-of-conduct.md). By participating you agree to keep discussions respectful and constructive.
