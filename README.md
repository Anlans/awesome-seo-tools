## Keyword Research

- [Ahrefs Keywords Explorer](https://ahrefs.com/keywords-explorer) - Database of 20+ billion keywords with difficulty scores, SERP features, and click metrics.
- [Semrush Keyword Magic Tool](https://www.semrush.com/analytics/keywordmagic/) - Massive keyword database with grouping, filtering, and intent breakdowns.
- [Google Keyword Planner](https://ads.google.com/home/tools/keyword-planner/) - Free keyword volume and competition data straight from Google Ads.
- [AnswerThePublic](https://answerthepublic.com/) - Question-based keyword discovery from autocomplete data.
- [Keyword Surfer](https://surferseo.com/keyword-surfer/) - Free Chrome extension showing search volumes directly in Google SERPs.
- [Keyword Sheeter](https://keywordsheeter.com/) - Generates thousands of keyword ideas from seed terms.
- [Ubersuggest](https://neilpatel.com/ubersuggest/) - Keyword suggestions, content ideas, and competitor data in one dashboard.
- [AlsoAsked](https://alsoasked.com/) - Related questions and "People Also Ask" clustering from real SERPs.
- [Exploding Topics](https://explodingtopics.com/) - Early trend and keyword discovery across industries.

## Rank Tracking

- [Ahrefs Rank Tracker](https://ahrefs.com/rank-tracker) - Daily position tracking with mobile/desktop split and local SERP support.
- [Semrush Position Tracking](https://www.semrush.com/projects/) - SERP monitoring with visibility score and competitor comparison.
- [AccuRanker](https://www.accuranker.com/) - Fast rank tracking focused on speed and integration with analytics tools.
- [Serpstat](https://serpstat.com/) - All-in-one SEO platform with rank tracking, keyword research, and backlink analysis.
- [Nightwatch](https://www.nightwatch.io/) - White-label rank tracker with localization and scheduling features.

## Backlink & Link Building

- [Ahrefs Site Explorer](https://ahrefs.com/site-explorer) - Backlink index of billions of pages with referring domain filtering.
- [Majestic](https://majestic.com/) - Trust Flow / Citation Flow metrics and backlink history maps.
- [Moz Link Explorer](https://moz.com/link-explorer) - Link analysis with Domain Authority and Spam Score metrics.
- [CognitiveSEO](https://www.cognitiveseo.com/) - Backlink monitoring with link risk assessment and disavow file generation.
- [Hunter.io](https://hunter.io/) - Email finder for outreach and digital PR link building.
- [Pitchbox](https://pitchbox.com/) - Outreach automation platform for link building campaigns.
- [Monitor Backlinks](https://monitorbacklinks.com/) - Backlink monitoring with spam score alerts.
- [Linkody](https://www.linkody.com/) - Backlink tracking with disavow file management.

## Technical SEO & Crawling

- [Screaming Frog SEO Spider](https://www.screamingfrog.co.uk/seo-spider/) - Desktop crawler for site audits, redirects, and duplicate detection.
- [Sitebulb](https://sitebulb.com/) - Visual crawl reports with prioritization and issue severity scoring.
- [Lumar (formerly DeepCrawl)](https://www.lumar.io/) - Enterprise cloud crawler with API access and workflow automation.
- [Sitechecker](https://sitechecker.pro/) - Website audit and SEO monitoring with crawl reports.
- [contentking](https://www.contentkingapp.com/) - Content auditing focused on crawl depth and page status tracking.

## Search Console & Webmaster Tools

- [Google Search Console](https://search.google.com/search-console) - Performance data, index coverage, and Core Web Vitals reports from Google.
- [Bing Webmaster Tools](https://www.bing.com/webmasters) - Indexing, keyword data, and SEO reports from Bing.
- [IndexNow](https://www.indexnow.org/) - Protocol for instant content discovery across participating search engines.

## Content Optimization & AI

- [SurferSEO](https://surferseo.com/) - On-page optimization with content score against top-ranking competitors.
- [Clearscope](https://www.clearscope.com/) - Content optimization with keyword relevance and readability scoring.
- [MarketMuse](https://www.marketmuse.com/) - AI-driven content strategy and topic modeling.
- [Frase](https://www.frase.io/) - AI content briefs generated from top-ranking SERP results.
- [Content at Scale](https://contentatscale.ai/) - Long-form AI writing optimized for search intent.
- [NeuronWriter](https://neuronwriter.com/) - Content optimization with SERP-based semantic suggestions.

## Free SEO Utilities

- [PageSpeed Insights](https://pagespeed.web.dev/) - Lab and field data for Core Web Vitals from Google.
- [Rich Results Test](https://search.google.com/test/rich-results) - Validates structured data for Google rich results.
- [Mobile-Friendly Test](https://search.google.com/test/mobile-friendly) - Checks mobile usability of any URL.
- [GTmetrix](https://gtmetrix.com/) - Page speed analysis with waterfall breakdowns and recommendations.
- [Wordfence](https://www.wordfence.com/) - Free security scanner useful for protecting link-acquiring sites.

## Local SEO

- [BrightLocal](https://www.brightlocal.com/) - Local SEO platform with citation building and review monitoring.
- [Whitespark](https://whitespark.ca/) - Local citation finder and Google Business Profile rank tracker.
- [Yext](https://www.yext.com/) - Enterprise location data and listings management.
- [Semrush Listing Management](https://www.semrush.com/local/) - Local listings sync and review management across directories.

## Analytics & Reporting

- [Google Analytics 4](https://analytics.google.com/) - Standard web analytics with an event-based tracking model.
- [Looker Studio](https://lookerstudio.google.com/) - Free reporting dashboards connecting to 600+ data sources.
- [Similarweb](https://www.similarweb.com/) - Traffic intelligence and competitor benchmarking.
- [Plausible](https://plausible.io/) - Lightweight, privacy-friendly web analytics.

## Browser Extensions

- [SEOquake](https://www.seoquake.com/) - On-page SEO metrics overlay for any page.
- [Keywords Everywhere](https://keywordseverywhere.com/) - Keyword volumes and CPC data embedded in search results.
- [Ahrefs SEO Toolbar](https://ahrefs.com/seo-toolbar) - SERP analysis with DR/UR metrics and redirect tracing.
- [Wappalyzer](https://www.wappalyzer.com/) - Technology stack identification for competitor research.
- [Detail](https://detail.co/) - View metadata, Open Graph tags, and JSON-LD for any page.

- [n8n](https://n8n.io/) - Workflow automation for DIY SEO pipelines and reporting.

- [GoAccess](https://goaccess.io/) - Real-time log analyzer for crawling and traffic insight.
